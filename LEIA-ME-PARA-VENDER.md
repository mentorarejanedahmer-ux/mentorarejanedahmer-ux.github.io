# Pacote comercial do Social Seller

Este pacote contém um aplicativo completo e instalável para organização de Social Selling.

## Arquivos

- `index.html`: aplicativo completo.
- `manifest.webmanifest`: dados de instalação.
- `sw.js`: funcionamento offline e atualização.
- `icon.svg`: ícone.
- `PROMPT-PARA-CRIAR-O-APLICATIVO.md`: prompt de personalização para cada compradora.

## Entrega para a cliente

Personalize nome, cores, público ideal, oferta e mensagens. Publique os arquivos em uma hospedagem HTTPS. A cliente abre o endereço no celular e toca em **Instalar no celular**.

Os dados cadastrados ficam no aparelho da cliente. Oriente-a a usar **Fazer backup** regularmente.
